J1 Code

Creator and maintainer · 2026

J1 Code is my fork of T3 Code, an open-source desktop app for running AI coding agents. It's what I used to build this site.

I added cross-provider delegation, so one agent can hand a bounded task to a worker on a different model and review what comes back. It also imports saved Claude Code and Codex conversations, follows live sessions, and keeps chats running in the Windows tray after the window closes.

Built with TypeScript, Electron, React, MCP

Gyromi

Creator and lead developer · 2026

Gyromi puts manga and light novels, Audiobookshelf audiobooks, and Stremio-compatible video into one app with a shared home screen and sync across devices. It runs on Windows and Android and builds on the open-source Mangayomi project.

Sync works offline-first through the Google Drive REST API, and credentials are hashed with PBKDF2-HMAC-SHA256.

Built with Flutter, Dart, Rust

Auto Apply

Creator and lead developer · 2026

A Python and React app that collects internship postings from LinkedIn, Indeed, and Handshake into one feed and uses Playwright to work through multi-step applications. Nothing gets submitted until I've reviewed it.

An IMAP email parser picks up interview invites and status changes and feeds a live Kanban board over WebSockets. The screenshots use demo data.

Built with Python, FastAPI, React, Playwright, WebSockets

Media Classifier

Lead developer · 2025 – present

A pipeline that sorts a large media library without doing it by hand. It pulls frames with OpenCV and scores each file on three signals: visual similarity from CLIP embeddings, watermark text from OCR, and fuzzy filename matching, weighted 30/40/30.

Files that score 0.90 or higher are filed automatically. Anything from 0.50 to 0.89 goes to a review queue on a FastAPI and Streamlit dashboard that also talks to Plex.

Built with Python, PyTorch, CLIP, OpenCV, FastAPI, Streamlit
